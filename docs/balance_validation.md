# 数值平衡实机验收

`RunMetrics` 会在正式关卡结束时展示本局战斗时间、等级、击败数、带出金币、总伤害、平均 DPS，以及普通怪、精英、Boss 的平均 TTK。TTK 从敌人第一次受到有效伤害开始，到其死亡为止；技能选择和结算暂停不会计入战斗时间。

## 验收流程

1. 从 `LevelSelect` 进入正式关卡；技能体验场和怪物试炼场不计入验收。
2. 正常游玩，不刻意静止刷怪；至少击败一只精英和 Boss。
3. 通关或失败后，在结算面板记录“实测 TTK”和“带出金币”。
4. 将结果与下表的目标比较；只调整 `data/balance.gd` 中的常量，并再次进行同条件验证。

| 维度 | 目标 | 记录位置 |
| --- | --- | --- |
| 普通怪 TTK | 3 秒 | 结算报告“普通” |
| 精英 TTK | 10 秒 | 结算报告“精英” |
| Boss TTK | 75 秒 | 结算报告“Boss” |
| 本局永久金币 | 150 ~ 250 | 结算报告“带出金币” |

# 技能与专属强化表

本表汇总全部技能（武器）及其专属强化，供开发时快速了解各技能机制、数值与强化效果。
**维护约定：任何新增/修改技能或专属强化后，必须同步更新本表。**

数据源：`skill_list.csv`（专属强化）+ `scripts/Skill/SkillCatalog.gd`（武器解锁/数量卡/通用/金币）+ 各武器场景脚本（基础数值）。

## 通用概念

- **武器解锁**：升级时可选"获得新武器"卡，最多同时拥有 5 种（`WeaponManager.MAX_NEW_SKILLS`）
- **数量卡**：每种武器有一张"+1 数量"专属卡（代码注册，满 6 级），多数武器随数量产生扇形/环形多条弹幕
- **属性操作类型**（`attribute_type`）：
  - `1` CURRENT_VALUE：在属性当前值上直接加
  - `3` BASE_SURPLUS_RATIO：按剩余比例叠加（当前值 + (1-当前比例)×值）
  - `4` BASE_RATIO：基础值 × 比例叠加（用于按百分比增强）
- **通用强化**（跨所有武器）：通用伤害 +10%/级、通用频率 +10%/级（各 6 级）
- **金币奖励**：金币宝箱 20 / 30 / 40 本局金币

## 1. 子弹（missile）— 默认初始武器

**机制**：发射瞬间自动瞄准最近敌人定方向，扇形齐射多发直线子弹（飞行中不追踪）；可穿透、反弹（反弹=飞出相机可视区弹回屏内，无反弹次数时离开屏幕即回收）。子弹发射后挂到场景根，世界坐标独立。

## 2. 回旋飞镖（dart）

**机制**：环绕玩家环形发射（从角色当前位置发出，每轮按当前飞镖数量**均匀平分角度**），飞出 1 秒（沿途对经过的敌人造成一次 0.5 伤害，每个敌人每轮命中一次），随后停在原地旋转造成伤害，旋转 0.5 秒后爆炸（2 伤害）并隐藏等待下次发射复用。**轮次门控**：上一轮全部飞镖完整播放（旋转+爆炸）后才发射下一轮，不会中途打断。旋转阶段每 0.2 秒对接触敌人造成 0.8 伤害。爆炸半径 = **1.2 × 碰撞体实际尺寸**（随"体积"强化动态放大，再乘"爆炸半径"卡倍率），判伤与落雷一致用**圆 vs 碰撞体 AABB 相交**。飞镖发射后挂到场景根，不释放节点，避免武器数组持有已释放引用。

**基础数值**：

| 属性 | 数值 |
| --- | --- |
| 轮次间隔 | 约 1.6 秒（一轮完整播放后发射） |
| 飞镖数量 | 3 |
| 飞镖伤害（旋转） | 0.8（每 0.2 秒一跳） |
| 飞行伤害 | 0.5（= 旋转 × 0.625） |
| 飞行时间 | 1 秒 |
| 飞镖速度 | 420 |
| 旋转时间 | 0.5 秒 |
| 爆炸伤害 | 2 |
| 爆炸半径 | 约 28.8px（1.2 × 碰撞体，动态） |

**专属强化**（6 级）：

| 强化 | 每级效果 | 属性 |
| --- | --- | --- |
| 飞镖伤害 | 伤害 +10% | dart_damage |
| 飞行速度 | 飞行速度 +10% | move_speed |
| 旋转时间 | 旋转时间 +20% | dart_spin_time |
| 爆炸伤害 | 爆炸伤害 +50% | dart_explosion_damage |
| 爆炸半径 | 爆炸半径 +15% | dart_explosion_radius |
| 飞镖体积 | 体积 +10%（同时放大爆炸半径） | dart_scale |
| 数量卡 | 数量 +1 | dart_number |

## 6. 落雷（lightning）

**机制**：定时从天上随机劈下闪电，落点在随机敌人位置附近随机偏移 60px（无敌人时落在玩家周围）。命中半径内敌人并造成伤害。**感电机制**：命中后按概率施加感电（基础 30%、持续 1 秒），感电中的敌人再次被落雷击中伤害 +50%；感电敌人身上显示蓝色火花（Enemy `_draw`）。
